# VICE HUB — Le QG GTA 6

Site de fans (non officiel) dédié à Grand Theft Auto VI : actualités sourcées, accès aux streams en direct, vidéos officielles, profil joueur, suivi des missions, badges et guide de lancement.

## Lancer le site

C'est une page unique, sans build : ouvre `index.html` dans un navigateur, ou active **GitHub Pages** (Settings → Pages → Branch `main`, dossier `/`).

## Sauvegarde des données

- Hébergé sur claude.ai : profil et missions synchronisés sur le compte, classement communauté et actus mises à jour automatiquement toutes les heures.
- Hébergé ailleurs (GitHub Pages, etc.) : le site bascule automatiquement en **sauvegarde locale** (navigateur). Utilise « Copier ma sauvegarde » dans *Mon profil* pour exporter tes données.
